# Генератор заданий №4 ЕГЭ по русскому языку

[![CI](https://github.com/rust08/ege-stress-trainer/actions/workflows/ci.yml/badge.svg)](https://github.com/rust08/ege-stress-trainer/actions/workflows/ci.yml)

Учебное приложение-тренажёр для **задания №4 ЕГЭ по русскому языку**:
даны пять слов, в четырёх ударение стоит верно, в одном — нет. Нужно найти
слово с неверным ударением и ввести его номер.

Проект писался вручную вдвоём — это наш первый совместный опыт: движок
заданий на Python, форма на PyQt6.

## Что умеет

- Хранит словарь верных ударений (`Ударения.txt`, 229 слов).
- Строит все варианты каждого слова с ударением на любой гласной.
- Делит варианты на верные и неверные (неверных — 449).
- Собирает задание из 5 разных слов: ровно 4 верных и 1 неверное.
- Возвращает задание, номер неверного слова и само слово.
- Форма: пять слов, поле ответа, кнопки «Продолжить» и «Ответить»,
  вкладка «Информация» с теорией и правилами по частям речи.

## Быстрый старт

Нужен Python 3.10+.

```bat
python -m pip install PyQt6
python Приложение.py
```

`requirements.txt` содержит только PyQt6 — этого достаточно для запуска.

## Проверка движка

```bat
python tests\smoke_test.py
```

Тест проверяет инварианты: 5 разных слов, ровно одно неверное, номер ответа
указывает на него, слово действительно из неверных вариантов. Запускается из
корня репозитория — движок читает `Ударения.txt` относительно текущей папки.

## Структура репозитория

```text
ege-stress-trainer/
```

## Формат данных

`Ударения.txt` — по одному слову на строку, ударная гласная записана
заглавной буквой:

```text
аэропОрты
бАнты
позвонИт
```

Источник слов — орфоэпический словарь ФИПИ для ЕГЭ.

## Как устроено

1. `ApplicationData.py` читает словарь и для каждого слова перебирает все
   варианты положения ударения.
2. Верные варианты отделяются от неверных.
3. `ApplicationData.task_and_response()` берёт 5 разных слов так, чтобы
   неверное было ровно одно, и возвращает `[слова, номер_ответа, слово]`.
4. `Приложение.py` раскладывает слова по пяти подписям, проверяет введённый
   номер и показывает «Правильно!!!» или верный ответ.

Подробно — [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md).
