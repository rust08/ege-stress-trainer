# Ударения — тренажёр задания №4 ЕГЭ

[![CI](https://github.com/rust08/ApplicationProject/actions/workflows/ci.yml/badge.svg)](https://github.com/rust08/ApplicationProject/actions/workflows/ci.yml)

Учебное приложение для тренировки **задания №4 ЕГЭ по русскому языку**:
в пяти словах нужно найти те, где ударение поставлено неверно.

Проект писался вручную вдвоём — это наш первый совместный опыт: сначала
движок заданий на Python, затем форма на PyQt.

## Что умеет

- Хранит словарь верных ударений (`Ударения.txt`, 229 слов).
- Генерирует все варианты каждого слова с ударением на любой гласной.
- Делит варианты на верные и неверные — неверных получается 449.
- Собирает задание из 5 разных слов так, чтобы верных среди них было
  от 1 до 4, и возвращает ответы.
- UI: форма с пятью вариантами, кнопкой «Продолжить» и вкладкой
  «Информация» с теорией по заданию.

Движок заданий готов и покрыт smoke-тестом. Форма сгенерирована из `.ui`
и пока не связана с движком — это следующий шаг (см. «Статус»).

## Быстрый старт

Нужен Python 3.10+.

```bat
pip install -r requirements.txt
python Приложение.py
```

`requirements.txt` — полный freeze окружения 2024 года; для самого приложения
достаточно **PyQt6**. Движок заданий работает без GUI и без зависимостей.

## Проверка движка

```bat
python tests\smoke_test.py
```

Тест проверяет инварианты: 5 разных слов в задании, от 1 до 4 верных,
ответ совпадает с верным словом. Запускается из корня репозитория — движок
читает `Ударения.txt` относительно текущей папки.

Ожидаемый вывод:

```text
слов в словаре: 229
вариантов слов: 678
неверных вариантов: 449
50 заданий собраны за 0.00 с
OK: движок заданий работает
```

## Формат данных

`Ударения.txt` — по одному слову на строку, ударная гласная записана
заглавной буквой:

```text
аэропОрты
бАнты
позвонИт
```

Из каждого слова движок делает все перестановки регистра гласных: одна из них
верная, остальные — неверные варианты для задания.
